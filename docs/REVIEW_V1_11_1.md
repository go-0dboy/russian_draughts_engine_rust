# Ревью v1.11.1

Проверка охватывает текущий source release, интерфейсы инструментов,
правила/поиск/TT и отмену поиска, корпус, обучение, статистический harness,
упаковку, обновление и документацию. Это инженерное ревью и регрессионные
проверки, а не формальное доказательство отсутствия всех ошибок.

## Исправлено

1. Match/SPSA не принимали публичный протокол classic_engine. Теперь клиент
   различает greeting и переводит ходы; legacy metadata в смешанной паре
   восстанавливается через канонический legal. Reference проверяет протокол
   до создания каталога результатов.
2. Ошибка при неполном backup обновлятора могла повредить исходники во время
   восстановления. Теперь полный backup предшествует удалению/замене исходников.
   ZIP traversal, дубликаты и symlink отклоняются до распаковки.
3. Обязательные файлы manifest и строгий порядок game/ply проверяются явно.
4. Matched STATIC/общий scale включены в основной релиз, не отдельный патч.
5. Все инструменты отформатированы, пользовательские ошибки краткие,
   долгие операции показывают прогресс/heartbeat. Wire tokens и форматы данных
   сохранены. Устойчивость хода отделена от устойчивости хода+оценки.
6. CI повторяет локальный gate, fmt стал обязательным; Cargo.lock входит в ZIP.

## Многопоточность

Поиск остаётся однопоточным. Асинхронный протокол передаёт владение движком
одному worker; одновременно читать/писать TT из нескольких поисков нельзя.
Stop использует отдельный Arc<AtomicBool> на поиск (Release/Acquire), старый
handle не отменяет следующий поиск. Проверены быстрый stop, повторный stop,
следующий поиск, ping/quit и завершение процесса.

Матчи/SPSA используют отдельную пару процессов на worker; сокеты/pipe и TT
не разделяются между игровыми заданиями. Результаты фиксируются по pair id,
а не по скорости завершения. При ошибке/прерывании дочерние процессы закрываются.
Rust core запрещает unsafe_code. Это не тест ThreadSanitizer и не реализация SMP.

## Оптимизация

Сохранены быстрый evaluator, bitboard movegen, packed u64, TT и SQL-фильтрация
пересечений одним проходом. Matched STATIC использует последовательное слияние
отсортированных записей с ограниченной памятью. Убрана повторная проверка SHA
в выборе reference-позиций после уже проверенного manifest.

Поиск и production-веса не менялись. Ускорение NPS или Elo не заявляется.
Дальнейшие измеряемые направления: память тюнера на миллионах samples,
пакетная индексация QRESOLVED, задержки replay/flush reference, профилирование
оценки и поиска на дамочных позициях. Изменения hot path требуют отдельного
benchmark и равного времени в матчах; они не смешиваются с этим выпуском.

## Ограничения

- Полный пользовательский PDN и обученные кандидаты здесь отсутствуют;
  integration использует реальные Rust binaries на небольшом воспроизводимом corpus.
- Проверка здесь на Linux. Termux/macOS повторяют gate на целевой машине.
- FINAL из уже использованного источника retrospective, не blind.
- QRESOLVED — отдельный capture-only minimax, не точная копия production qsearch.
- Reference не oracle; top-2/regret/MultiPV пока отсутствуют.
- HCE/pattern/внешние матчи ещё не доказали профессиональный уровень.
- Обновлятор восстанавливается после ошибок команд, но не обещает транзакционность
  при выключении питания или kill -9. Сохраняйте резервные копии важных данных.
- Старые незавершённые experiments нельзя resume после изменения их identity.
